# StyleWear — Online Clothing Store Prototype

## Business idea
StyleWear is a sample online clothing store for men's and women's fashion in Pakistan. The prototype demonstrates products, prices, a demo cart, an order request form, and basic financial planning.

## Files
- `index.html` — responsive website prototype with HTML, CSS and JavaScript.

## Sample financial estimates (PKR)
- Initial clothing stock: 100,000
- Website setup: 10,000
- Packaging: 5,000
- Marketing: 10,000
- Other startup costs: 5,000
- Total startup cost: 130,000
- Example funding: 80,000 personal savings + 50,000 family support
- Monthly sales estimate: 200,000
- Monthly expenses estimate: 150,000
- Estimated monthly profit: 50,000

These are illustrative classroom estimates, not verified market quotes or guaranteed results.

## AI tools used
ChatGPT was used to assist with the business concept, sample financial estimates, and prototype source code. Students should review the numbers and be prepared to explain the project.

## How to view
Open `index.html` in a web browser. Internet access is needed for the external product photographs.
